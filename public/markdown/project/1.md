### Tech Stack

- **Infrastructure** : AWS VPC, ALB, WAF, Auto Scaling, RDS(MySQL), ElastiCache(Redis), S3, Lambda, EventBridge, SQS, CloudWatch, Route53, Cognito, Secrets Manager, ACM
- **GCP** : GCP Cloud Storage, Storage Transfer Service
- **Application** : Flask, Nginx, MySQL

---

### Architecture

![AWS 아키텍처 구성도](/images/project/1-arch.png)

단일 서버 구조의 로컬 애플리케이션을 AWS 기반 고가용성 3-Tier 아키텍처로 마이그레이션한 프로젝트입니다.
AWS VPC 내 2개의 가용 영역에 Public/Private Subnet을 계층별로 구성하고 WAF + Security Group Reference 방식으로 계층 간 접근을 제어했습니다. Multi-AZ ALB + Auto Scaling으로 Web/App 계층을 이중화하여 인프라 고가용성을 확보했습니다.
RDS Master/Read Replica로 데이터 가용성을 확보하고, EventBridge + Lambda 백업 자동화와 SQS 기반 GCP 멀티 클라우드 백업으로 데이터 안정성을 높였습니다.
Cognito + 카카오 소셜 로그인(OIDC) 연동으로 인증을 구성하고, CloudWatch로 리소스 상태를 모니터링했습니다.

---

### Role

- **AWS 인프라 및 네트워크 구성**
  - VPC 설계: 2개의 가용 영역에 퍼블릭/프라이빗 서브넷(Web, WAS, DB) 계층별 분리 구성
  - 보안 그룹: 13개의 보안 그룹을 Security Group Reference 방식으로 계층 간 최소 권한 접근 제어 설계
  - NAT Gateway, Internet Gateway, 라우팅 테이블 구성

- **GCP 멀티 클라우드 데이터 전송**
  - S3 이벤트 알림 → SQS → GCP Storage Transfer Service 연동으로 이벤트 기반 자동 복제 구현
  - IAM 정책 설계: S3 데이터 접근 및 SQS 이벤트 처리 권한을 분리하여 최소 권한 원칙 적용

#### RDS 백업 자동화 & GCP 멀티 클라우드 백업

S3에 저장된 RDS 백업 데이터를 GCP Cloud Storage로 자동 전송하는 멀티 클라우드 백업 환경을 구성했습니다.

![RDS Backup 구조](/images/project/1-db_backup.png)

Lambda + EventBridge로 RDS 스냅샷을 S3에 자동 Export하고, S3 파일 변경 이벤트가 SQS 큐에 전달되면 GCP Storage Transfer Service가 이를 감지하여 GCP Cloud Storage(오사카 리전)로 자동 복제되는 구조입니다.

![GCP Storage transfer service](/images/project/1-sts.png)

IAM 정책은 S3 읽기와 SQS 읽기·쓰기 권한을 분리 부여하여 최소 권한 원칙을 적용했습니다.
