### Role

- **Front-end 개발**
  - 사용자 인증 및 관리: 회원가입, 로그인 페이지 및 유효성 검사 로직 구현, Redux를 활용한 사용자 인증 상태 관리
  - 마이페이지 및 대시보드: 사용자 프로필 관리 및 개인화된 산책 기록 리스트 인터페이스 구현
  - 실시간 산책 타이머: 산책 시작/종료 시간을 관리하고 실시간으로 경과 시간을 표시하는 타이머 기능 및 시간 데이터 저장 로직 구현

- **배포 및 운영 자동화**
  - CI/CD 파이프라인: GitHub Actions를 활용해 main 브랜치 push 시 자동 빌드 및 S3 배포 파이프라인 구축
  - 보안 관리: AWS 자격증명 및 외부 API 키를 GitHub Secrets로 관리하여 소스코드 내 민감 정보 노출 방지
  - 정적 호스팅: S3 + CloudFront을 사용하여 HTTPS 지원 및 CDN을 통한 콘텐츠 전송 최적화
  - 캐시 전략: 배포 후 CDN 캐시를 자동으로 갱신하여 사용자가 항상 최신 버전의 서비스를 제공받을 수 있도록 처리
